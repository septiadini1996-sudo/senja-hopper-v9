**Senja Hopper — Pos Udara.** A true-3D seaplane mail game in plain WebGL2 (hand-written engine, no libraries): fly hops across eight Indonesian islands — Bali → Nusa Penida → Lombok → Sumbawa → Flores → Sulawesi → Maluku → Papua — thread golden rings for bonus pay, and put the plane down on the destination airport's runway for a graded landing (S/A/B/C/D) and a TERKIRIM-stamped receipt. A compressed 24-hour game clock drives the whole sky — dawn mist, harsh midday *terik*, the golden *senja* hour, and starry nights lit by runway lamps, house windows and the plane's own landing light — and a deterministic (day, hour) weather table deals clear skies, overcast, rain and storms: every ticket on the morning board prints its departure hour and its forecast, and the flight keeps the board's promise. A hangar with ENGINE / FUEL TANK / HULL upgrades, challenges, pilot stats, and a persistent save. Four control schemes — keyboard, joystick, touch, gyro — over one normalized input frame, with ASSISTED/DIRECT handling, three camera views (chase near, chase far, cockpit), a live radar scope, and full English / Bahasa Indonesia switching. Runs in the browser, touch-first on iPad.

## Run it

```sh
node serve.ts        # then open http://localhost:8080
```

Or open the hosted copy on this repository's GitHub Pages site. No build step, no dependencies: `game/` is static files and ES modules.
